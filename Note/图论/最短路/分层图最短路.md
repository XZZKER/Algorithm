# 分层图最短路

当进入一个位置节点有不同的状态，并且节点个数 * 状态个数不会超时，那么可以把位置节点和状态的组合{位置节点，状态}看成一个节点，再跑最短路算法，重要的是**想清楚每个状态的转移，然后结合位置转移，排列组合出合法的节点转移**。

切记**相同位置节点的不同状态不是同一个节点**，还要题目可能只需要某种状态或者位置就能结束。
