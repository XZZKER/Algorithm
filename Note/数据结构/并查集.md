# 并查集

## 操作

- 查询：查询该节点的根节点，复杂度`O(log(n))`
- 合并：合并两个连通块，复杂度`O(log(n))`

## 模板

```c++
class UnionFind {
    std::vector<int> root, count;

public:
    int size;

    UnionFind(int n) : root(n), count(n, 1), size(n) {
        std::iota(root.begin(), root.end(), 0);
    }

    int find(int x) {
        return root[x] == x ? x : (root[x] = find(root[x]));
    }

    bool isSame(int x, int y) {
        return find(x) == find(y);
    }

    bool merge(int x, int y) {
        int from = find(x), to = find(y);
        if (from == to)
            return false;
        root[from] = to;
        count[to] += count[from];
        size--;
        return true;
    }

    int getSize(int x) {
        return count[find(x)];
    }
};
```
