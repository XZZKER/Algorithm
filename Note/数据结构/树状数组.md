# 树状数组

对于每个`c[i]`，`lowbit(i)`划分了`c[i]`的管辖范围，`c[i]`维护`[i - lowbit(i) + 1, i]`中的数   

![](E:\Note\算法\数据结构\树状数组.png)

## 操作

- 前缀查询：按照`lowbit(i)`把`[1, i]`拆段，复杂度`O(log(n))`
- 区间查询：类比前缀和，复杂度`O(log(n))`
- 单点更新：按照`lowbit(i)`更新`[i, n]`，复杂度`O(log(n))`
- 区间更新：
## 优缺点
- 代码短，常数小
- 利用前后缀实现的区间查询仅支持**可逆**(可差分)的运算
## 模板

```c++
template<typename T>
class FenwickTree {
    vector<T> tree;

public:
    FenwickTree(int n) : tree(n + 1) {}

    void update(int i, int v) {
        while (i < tree.size()) {
            tree[i] += v;
            i += i & -i;
        }
    }

    T pre(int i) {
        T tmp = 0;
        while (i > 0) {
            tmp += tree[i];
            i -= i & -i;
        }
        return tmp;
    }

    T query(int l, int r) {
        return pre(r) - pre(l - 1);
    }
};
```
