## 距离和
- 作用：求一个数组num对target的距离和（差的绝对值之和）

- 过程：将要求的部分与用前缀和好求的部分组合成规则图形（算式）

  ![](E:\Note\算法\数据结构\距离和.png)
 ```c++
 int left = target * (i - 1) - s[i - 1];
 int right = s[n] - s[i - 1] - target * (n - i + 1);
 int ans = left + right;
 ```
